# FORMA — цифровой маркетплейс

Первый frontend-MVP магазина цифровых продуктов.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages для ветки `main` и корневой папки.

## Сейчас реализовано
- Адаптивный каталог (на мобильных — две колонки)
- Фильтрация по категориям и поиск
- Добавление товаров в демонстрационную корзину
- Светлая визуальная система FORMA

Оплата, аккаунты, поддержка и серверная часть пока не подключены. Товары и изображения демонстрационные.
